## 🚀 1. லோக்கலாக மொபைல் அல்லது கம்ப்யூட்டரில் பயன்படுத்துவது எப்படி?
1. இந்த ஜிப் கோப்பை உங்கள் சாதனத்தில் `Extract` (அன்ஜிப்) செய்யவும்.
2. அதில் உள்ள `index.html` கோப்பைத் தொட்டு கூகுள் குரோம் (Google Chrome) பிரவுசரில் திறக்கவும்.
3. இணையமே தேவையில்லை; ஆஃப்லைனிலேயே அனைத்து பாடங்கள், 8 அறிவியல் வரைபடங்கள், 10 மதிப்பெண் சமூக அறிவியல் மேப் மற்றும் 8 மதிப்பெண் கணித வரைபடங்கள் இயங்கும்.

## 🌐 2. GitHub Pages-ல் பதிவேற்றி லைவ் ஆக்குவது எப்படி? (2 நிமிட வேலை)
எந்த வெளி ஹோஸ்டிங் தளமும் இல்லாமல் உங்கள் கிட்ஹப்பிலேயே (GitHub) இதை நிரந்தரமாக இலவசமாக இயக்கலாம்:

1. **GitHub.com** சென்று உங்கள் கணக்கில் லாகின் செய்து **New Repository** உருவாக்கவும் (பெயர்: `yadhavan-ai-tuition`).
2. இந்த ஃபோல்டரில் உள்ள அனைத்து கோப்புகளையும் (`index.html`, `manifest.json`, `service-worker.js`, `guide.html`, மற்றும் `icons/` ஃபோல்டர்) GitHub-ல் பதிவேற்றவும் (`Upload files` -> `Commit changes`).
3. GitHub Repository-ல் **Settings** -> இடது பக்கம் உள்ள **Pages** பகுதிக்குச் செல்லவும்.
4. **Branch** என்பதில் `main` (அல்லது `master`) என்பதைத் தேர்வு செய்து **Save** கொடுக்கவும்.
5. அடுத்த 1 நிமிடத்தில் உங்கள் ஆப் லைவ் ஆகிவிடும்! உங்களுக்கான தனித்த லிங்க் கிடைக்கும்:
   👉 `https://<your-username>.github.io/yadhavan-ai-tuition/`

## 📲 3. மொபைலில் "Install App" செய்வது எப்படி?
1. அந்த GitHub Pages லிங்கை மாணவர்கள் தங்கள் மொபைல் குரோம் (Chrome) பிரவுசரில் திறக்கும்போது, மேலே உள்ள **"📲 Install App"** பட்டன் ஒளிரும்.
2. அதைத் தொட்டவுடன் உங்கள் போன் திரையில் **"Install Yadhavan AI Tuition"** என்று தோன்றும்.
3. `Install` கொடுத்தால், கூகுள் பிளே ஸ்டோர் ஆப் போலவே மாணவரின் மொபைல் ஹோம் ஸ்கிரீனில் யாதவன் லோகோவுடன் ஒரு தனி ஆப்பாக அமர்ந்துவிடும்!
